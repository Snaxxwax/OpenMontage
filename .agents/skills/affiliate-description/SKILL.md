# Affiliate Description (Asymmetric)

## When to Use

Use this when you need **a publish-ready description** that includes affiliate/tool links without breaking trust or brand tone.

Always apply the brand rules in `.Codex/AGENTS.md` first.

## Inputs (ask/derive)

- Video title + target platform (YouTube long-form vs Shorts)
- 1–2 sentence thesis (what’s actually happening)
- The **system** + **chokepoint** + **beneficiary** + **leverage point**
- Audience sophistication (operators/founders/analysts default)
- Any tools you *actually used* in production (preferred), or the workflow stack being taught
- Any existing links the user must include (newsletter, website, doc, template)

## Output (always include)

1. One-sentence hook
2. 1 short summary paragraph (no hype)
3. **Affiliate stack** (3–7 items max)
4. Lead magnet CTA (optional but recommended)
5. Disclosure line (explicit)
6. Timestamps (if ≥ 4 sections exist)
7. Pinned comment draft

## Process

### 1) Make leverage legible first

Before writing anything, state internally:
- **What is the chokepoint?**
- **Who benefits from the current structure?**
- **What small input moves the whole system?**

If you can’t answer those, fix the thesis before formatting the description.

### 2) Write the hook (1 sentence)

Rules:
- No creator voice.
- No hype.
- Name the hidden mechanism or chokepoint.

Template:
> You’re watching the surface story — the real control surface is **[chokepoint]**.

### 3) Write the summary paragraph (4–7 lines)

Requirements:
- One concrete system example.
- One incentive explanation.
- One consequence (“who pays”).
- One operator takeaway (“what to watch / where leverage sits”).

### 4) Build the affiliate stack (trust-first)

Rules:
- Only recommend tools that plausibly fit Asymmetric workflows.
- Prefer categories: research, mapping, automation, documentation, privacy/security, books/reports.
- Avoid low-status affiliate clutter (keep it tight and relevant).
- Avoid junk gadgets, generic Amazon filler, lifestyle products, “life-changing” language.
- Each item gets **1 line**: what it’s for + why it fits the workflow.

Format:
> TOOLS (affiliate links)  
> - [Tool] — [job it does] (why it fits: [operator value])

### 5) Lead magnet CTA (optional)

Make it process-based, not personality-based.

Template:
> If you want the exact leverage-mapping template used here, grab it here: [link]

### 6) Disclosure line (mandatory)

Blunt and explicit:
> Disclosure: Some links are affiliate links. If you use them, the channel may earn a commission at no extra cost to you. I only link tools I’d actually use.

### 7) Timestamps (when applicable)

Only include if you can segment cleanly into chapters.
Use Asymmetric chapter naming where possible (e.g., `THE SURFACE STORY`, `THE CHOKEPOINT`).

### 8) Pinned comment draft

Tone: controlled, brief.
Include:
- 1-line thesis
- 1 CTA (template/stack)
- disclosure reminder (short)

## QA Checklist (fail if any are “no”)

- Leverage point is obvious within 2 sentences
- No sponsor voice / no creator-energy phrasing
- Recommendations match the episode’s workflow (not generic)
- Disclosure is explicit
- Description reads like a private briefing, not marketing copy
