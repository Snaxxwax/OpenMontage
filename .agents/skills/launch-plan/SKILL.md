# Launch Plan (Asymmetric)

## When to Use

Use this to design a **launch sequence** that compounds trust while still earning reach.

Always apply the brand rules in `.Codex/AGENTS.md` first.

## Inputs (ask/derive)

- Platform focus: YouTube long-form, Shorts, or mixed
- Cadence + production capacity (solo vs team)
- Primary domain(s): tech, finance, geopolitics, infra, creator economy, etc.
- Risk tolerance: “name names” vs “mechanism-first”
- Monetization posture: none, light affiliate, lead magnet, premium reports later

## Output (always include)

- 10–16 episode slate with:
  - title (using the title engine)
  - pillar
  - system + chokepoint
  - leverage point + beneficiary
  - hero object + diagram type
  - thumbnail family (power / mechanism / consequence)
  - trust vs reach vs monetization role
  - production difficulty (low/med/high)
- Sequencing logic (why this order)
- Lead magnet tie-ins (optional but recommended)
- 30/60/90-day publishing plan

## Process

### 1) Define the “home territory”

Pick one repeating frame:
- “Where the Leverage Is in X” as the flagship
- plus 1 alternate format (e.g., “Who Really Controls X?”)

### 2) Build the slate as a portfolio

Balance:
- 40% **Hidden Control** (trust + authority)
- 30% **System Leverage** (reusable models)
- 20% **Extraction Layers** (stakes + shareability)
- 10% **Power Networks / Optimization Warfare** (spikes + series hooks)

### 3) Sequence for compounding trust

Order rule of thumb:
1. Big legible chokepoint (easy to believe)
2. Mechanism episode (teaches the viewer how to think)
3. Consequence episode (stakes + who pays)
4. Repeat with a new domain, keeping the same analytic frame

### 4) Attach lead magnets to workflows, not opinions

Examples:
- leverage-mapping template
- “fee stack” worksheet
- control-surface checklist
- research stack + sources index

### 5) Production difficulty honesty

Mark each episode:
- **Low**: mostly diagrams + narration
- **Med**: requires sourcing + data visuals
- **High**: requires network mapping, FOIA-style sourcing, or multiple case studies

## QA Checklist

- Each episode has a named chokepoint (not a vibe)
- Slate has at least 3 “flagship” episodes that define the channel
- Sequencing escalates complexity over time
- Monetization never weakens the thesis
