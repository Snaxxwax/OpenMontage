# Asymmetric Episode (Wrapper)

## Do this (in order)

1. Apply brand rules from `.Codex/AGENTS.md`.
2. Follow OpenMontage ideation guidance: `skills/pipelines/explainer/idea-director.md`.
3. Output each idea using the Asymmetric “episode ideas” schema (below).

## Output schema (per idea)

- Title
- Pillar (Hidden Control / System Leverage / Extraction Layers / Power Networks / Optimization Warfare)
- Core hook (1 sentence)
- Hidden structure (what layer governs the outcome)
- Leverage point (the tiny lever)
- Likely winner / loser
- Hero object
- Diagram type (chokepoint map / ownership web / value flow / leverage map / pressure map / control hierarchy)
- Thumbnail angle (power / mechanism / consequence) + thumbnail family
- Monetization fit (allowed categories only)
- Why it should perform (search + intrigue + stakes)

## Acceptance checks

- Leverage is identifiable in < 2 sentences
- No generic “topic overview” framing
- One dominant idea (no multi-angle salad)
