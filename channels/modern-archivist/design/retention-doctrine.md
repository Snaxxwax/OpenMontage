# Modern Archivist Retention Doctrine

## Channel target
The Modern Archivist / Failure Ledger is a forensic business-crime documentary channel led by a sardonic digital archivist. The target output is not a research deck with narration; it is cinematic case-building that turns corporate and product failures into thesis-driven autopsies. The failure thesis leads; evidence defends it.

## Influence blend
- Coffeezilla: confrontation, evidence, contradictions, named stakes, and the moment where the record catches up to the claim.
- MagnatesMedia: cinematic pacing, escalating stakes, act turns, compression montages, and business-failure momentum.
- Modern Archivist: teal archive, crimson critical error, dry voice, flat case-file UI, deterministic Remotion animation, and a character who punctuates rather than hosts every second.

## Evidence hierarchy
1. Primary evidence: first-party documents, archived pages, filings, repositories, public records, named interviews, transcripts, and dated source material.
2. Derived editorial visuals: timelines, failure graphs, annotated code, contradiction cards, quote extraction, and case-file boards derived from primary or secondary evidence.
3. Brand-world visuals: teal archive interfaces, ledger pages, dossier folders, controlled glitch/error motifs, and the Archivist puppet.
4. Illustrative cinematic metaphors: internally labeled non-evidence visuals used only to clarify mood, stakes, or system failure.

## Character usage
- The Archivist is an anchor, not a permanent host or bottom-right mascot.
- Use teal baseline for framing, context, dry setup, and controlled analysis.
- Use crimson red for scarce pattern interrupts: critical contradictions, stakes spikes, or terminal failure moments.
- Return the character for hook, thesis, transitions, critical-error roasts, stakes reframes, and outro.
- Evidence-heavy body sections should usually be full-screen editorial visuals with the character hidden.

## Retention cadence
- Require a visual change every 3-6 seconds: crop, push, reveal, highlight, card movement, graph update, character action, or typography beat.
- Introduce a new sequence type every 20-35 seconds during dense sections.
- Return to the anchor every 45-60 seconds during evidence-heavy sections.
- Create an act turn every 90-150 seconds for long episodes.
- Do not hold a static source card longer than 6 seconds unless the motion plan justifies it.

## Visual modes
- `monologue`: character-led framing, thesis, transition, or outro.
- `case_file`: evidence cards, stamped labels, red-string links, source labels, contradiction reveals.
- `cinematic_metaphor`: illustrative-only mood or stakes visual with explicit internal label.
- `failure_graph`: cause/effect nodes, failure paths, entity relationships, collapse sequence.
- `code_walkthrough`: local code text with line highlights and forensic annotations.
- `data_sequence`: chart, metric collapse, KPI grid, or visualized timeline from local data.
- `critical_error`: short crimson pattern interrupt, roast, contradiction, or alert.
- `outro`: payoff, lesson, ledger close, or next-case tease.

## Anti-patterns
- Long static receipts.
- Generic stock montage without a clear evidence relationship.
- Permanent bottom-right mascot.
- Unlabelled illustrative material.
- Live network fetch during render.
- WebGL or image-to-video workarounds for core character acting.
- Cinematic gloss that weakens source provenance.
