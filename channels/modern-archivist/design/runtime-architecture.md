# Modern Archivist Runtime Architecture

This is the source-controlled runtime reference for the Modern Archivist / Failure Ledger channel package.

Diagram: `runtime-architecture.svg`

## Core rule

Remotion / React is the canonical final assembler. Declared mixed-runtime production is allowed when it improves quality: HyperFrames can render approved premium segment assets, and FFmpeg can perform utility operations such as probe, trim, normalize, mux, and cache preparation.

The guardrail is no hidden runtime substitution and no unapproved visual-paradigm swap.

## Render sequencing

1. Plan evidence visual modes early.
2. Collect/source/stage public footage, artifacts, archived pages, and UI recreation opportunities.
3. Render/cache source-heavy scenes or HyperFrames premium inserts as local assets when useful.
4. Lock narration and section timings.
5. Run final Remotion assembly with cached source/background plates, captions, audio, and final labels.
6. Run evidence, visual identity, and render-QC gates.

## Why this exists

The previous root-level `diagram.png` was a generic placeholder and not a meaningful architecture artifact. Channel-specific runtime documentation belongs under `channels/modern-archivist/design/` so it travels with the channel package and does not imply a generic OpenMontage-core architecture.
