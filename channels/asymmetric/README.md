# Asymmetric Channel Kit (OpenMontage)

This folder is the versioned "channel brain" for Asymmetric: strategy and templates.

**Source of truth for the current visual identity**
- Playbook: `styles/asymmetric.yaml`
- Identity spec: `DESIGN.md`
- Logo: `assets/asymmetric-logo.png`

## How This Folder Is Used

- `Strategy/` holds the current channel identity and operating rules.
- `Templates/` are Markdown templates for research briefs, production notes, and analytics reviews.
- `Topics/` is where new topic notes/backlogs should be authored.
- `Productions/` is where per-video production notes should be authored.

Note: this repo intentionally does **not** import content from `~/Asymmetric`; only the structure is mirrored here so production inputs live alongside the OpenMontage playbook.

## Style Lock

All productions for Asymmetric should use the current playbook:
- Near-black editorial base (`#050608`, `#11151C`)
- Semantic signal colors:
  - Amber `#F5A400` = leverage/control/chokepoints
  - Cyan `#3F8FA3` = structure/flow/map logic
  - Red `#D64545` = explicit cost/failure/extraction only
- Motion: meaningful state change every ~2–4s; never unchanged > ~4s
