# Brand Identity — Asymmetric (Current)

This is the **current** Asymmetric identity used by OpenMontage. It mirrors:
- `DESIGN.md`
- `styles/asymmetric.yaml`

Tagline: **Where the leverage is.**

## What This Should Feel Like

Faceless **systems briefing**. Authority comes from structure, evidence, and packaging.

- Dark editorial framing
- Map-room clarity (flows, boundaries, chokepoints)
- Object-led motion (the control surface is the hero)
- Restrained depth only for hierarchy (no glossy 3D)

## Color Semantics (Non-Negotiable)

Base:
- Near Black: `#050608`
- Deep Slate: `#11151C`
- Graphite: `#2A3142`
- Bone: `#F3F5F7`
- Muted Steel: `#8A95A6`

Signal (semantic):
- Amber `#F5A400` = control / leverage / chokepoint (default hero signal)
- Cyan `#3F8FA3` = structure / flow / map logic
- Red `#D64545` = cost / extraction / failure only

Rules:
- Default to **one** signal color per frame
- Never use signal colors as decoration
- Do not use all three signal colors in one frame

## Typography

Max two families per frame:
- Primary body: `Inter`
- Display: `Space Grotesk`
- Data/code layer: `IBM Plex Mono`

## Diagram Language

Primitives:
- circles = nodes
- lines = flows
- wedges = leverage
- boxes = boundaries
- valves/gates = control points

## Motion Rules

- Meaningful state change every **2–4 seconds**
- No visual state remains unchanged for **> ~4 seconds**
- Pattern interrupt every **8–15 seconds**
