# Diagram Devices

This directory will hold reusable specifications and SVG/CSS templates for Asymmetric's recurring diagram devices.

## What goes here
- Device specs (meaning + animation contract) as `.md`
- SVG templates and example compositions as `.svg`
- Optional JSON parameter schemas as `.json`

## Naming
- `device-<name>.<ext>` for stable, reusable devices.
- Avoid episode numbering.

## Notes
Keep devices diagram-native: SVG layers + CSS variables (colors from `brand/tokens.json`).
