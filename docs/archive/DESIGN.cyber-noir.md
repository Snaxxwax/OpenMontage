# Visual Identity: The Code that Ate the World

## Style Prompt
Cyber-noir prestige documentary aesthetic. High-contrast obsidian backgrounds with glowing gold and cyan accents. Minimalist but high-energy motion graphics. Data-heavy but readable. Technical elegance.

## Colors
- **Background:** `#0A0A0B` (Obsidian) - The primary canvas.
- **Primary Accent:** `#FFD700` (Gold) - For prestige, wealth, and power themes.
- **Secondary Accent:** `#00F0FF` (Cyber Cyan) - For code, data, and future-tech themes.
- **Text Primary:** `#FFFFFF` (White) - For high-contrast headers.
- **Text Secondary:** `#A0A0A0` (Silver) - For lower-priority labels and data.

## Typography
- **Primary Font:** `Space Grotesk` - Bold, technical, modern.
- **Secondary Font:** `Inter` - Clean, readable for body text.

## What NOT to Do
- No generic gradients (use radial glows).
- No saturated reds or greens (keep it cyber-noir).
- No round/friendly UI elements (keep corners sharp or slightly beveled).
- No "standard" stock footage (prefer glitchy, high-contrast, or stylized tech b-roll).
