# Asymmetric Thumbnail Packaging (Wrapper)

## Do this (in order)

1. Apply brand rules from `.claude/CLAUDE.md`.
2. Follow OpenMontage publish guidance: `skills/pipelines/explainer/publish-director.md`.
3. Add the Asymmetric thumbnail pack below.

## Thumbnail pack (always 3 variants)

For each variant: power / mechanism / consequence.
Each variant includes a **paired title + thumbnail concept** (three materially different frames).

- Title option (use the title engine library; mechanism/chokepoint-first)
- Headline text (2–5 words)
- Hero object
- Dominant internal role (Gatekeeper / Strategist / Broker / Extractor / Swarm)
- Thumbnail family (Hidden Operator / System Map / The Breach / Extraction)
- Composition notes (one dominant idea, one focal subject, mobile-first)
- Leverage marker placement (what is highlighted)
- Signal color choice:
  - Amber = control/leverage/chokepoint
  - Cyan = structure/flow/map logic
  - Red = explicit cost/damage/extraction/failure only
- Why this variant might win (curiosity + clarity + stakes)

## Tests (must pass)

- 2-second test: viewer can identify leverage point immediately
- Mobile readability test: works at small size
- No clutter / no collage
- Only one internal visual role dominates
