# Asymmetric Script (Wrapper)

## Do this (in order)

1. Apply brand rules from `.claude/CLAUDE.md`.
2. Follow OpenMontage scripting guidance: `skills/pipelines/explainer/script-director.md`.
3. Add the Asymmetric-specific passes below.

## Deliverable (when asked for a script)

- 3 working title options (use the title engine library)
- 3 thumbnail angles (power / mechanism / consequence)
- Cold open + sectioned outline + full script
- Motion notes + chapter cards + CTA placement (if relevant)
- Final pass: “where is the leverage?”

## Asymmetric passes

### Narrative modes

Use at least two of: Cartographer / Operator / Skeptic / Realist. For long-form, aim for three.

### Cold open (0:00–0:35)

- One contradiction
- One concrete system
- One open loop

### Chapter cards

Prefer the chapter bank from `.claude/CLAUDE.md` (e.g., `THE SURFACE STORY`, `THE CHOKEPOINT`).

### Motion/retention reminders (inline notes)

- Meaningful state change every 2–4 seconds
- Pattern interrupt every 8–15 seconds
- Mode shift every 20–35 seconds

### CTA fit check

- Trust-first; no hard pitch
- If affiliates: include an explicit disclosure line

## Final test (must pass)

“Where is the leverage?” is answered clearly by the end of the script.
