# Visual Identity: Asymmetric (Systems Briefing Documentary)

Asymmetric is a **faceless systems-briefing** brand. Authority comes from structure, evidence, and packaging — not personality.

Tagline: **Where the leverage is.**

## Visual promise

This should feel like a **private briefing coming alive**:
- dark editorial framing
- rapid diagram evolution (maps, chokepoints, ownership webs)
- object-led motion (hero objects + marked control surfaces)
- restrained 2.5D depth only for hierarchy (not glossy 3D spectacle)

## Color semantics (non-negotiable)

Base:
- Near Black: `#050608`
- Deep Slate: `#11151C`
- Graphite: `#2A3142`
- Bone: `#F3F5F7`
- Muted Steel: `#8A95A6`

Signal (semantic):
- Institutional Amber: `#F5A400` = control / leverage / chokepoint
- Muted Steel Cyan: `#3F8FA3` = structure / flow / map logic
- Deep System Red: `#D64545` = cost / extraction / failure only

Rules:
- default to **one** signal color per frame
- never use signal colors as decoration
- never use all three signal colors in one frame

## Typography

- Primary: `Inter`
- Limited display: `Space Grotesk`
- Data layer: `IBM Plex Mono`

Rules:
- max two families per frame
- readability first; no novelty futuristic fonts

## Diagram language

Primitives:
- circles = nodes
- lines = flows
- wedges = leverage
- boxes = boundaries
- splits = hidden layers
- stacks = hierarchy
- valves/gates = control points

## Motion rules

- No visual state stays unchanged for > 4 seconds
- Meaningful change every 2–4 seconds (new highlight, arrow extension, crop shift, label swap)
- Pattern interrupt every 8–15 seconds

## Thumbnail system

Every serious upload ships 3 materially different variants:
- Power
- Mechanism
- Consequence

Hard rules:
- one dominant idea, one focal subject
- 2–5 words max, mobile readability first
- the leverage point must be identifiable in under 2 seconds
